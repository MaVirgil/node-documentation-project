Creating a Date object

Date objects in JavaScript are - surprisingly - used to represent points in time. Fundamentally a date object describes an amount of miliseconds before or after January 1st 1970, also known as "unix EPOCH time". This method of representing time came about as a result of the infamous Y2K bug, where - in order to save valuable memory capacity - computer systems storing dates only used two digits to represent the year, which made it impossible to differentiate between the years 2000 and 1900.
