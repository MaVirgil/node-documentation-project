Express.js

Express.js is a Node.js framework used to develop web-based applications. Compared to bigger frameworks like Spring or ASP.NET, Express feels very minimalist and simple to approach, with little to no boilerplate code needed to get a basic server up and running.

On this page we will create a small express server, serving an HTML-page and exposing some API endpoints using placeholder data.

Setting up a server

On a fresh Node.js project, run the command npm install express to declare and install the Express framework as a dependency. Alternatively we can manually declare Express as a dependency, and run npm install, either way works fine. Lastly add "type": "module" to your package.json, to use the ESmodule import syntax seen in the examples on this page.

Serving static files

Now we've served an HTML page, but we might want to give that page some style with a CSS file, and maybe even some dynamic behaviour with a script. If we point to an external CSS file in the head of our HTML, the client will not be able to fetch it, because we are not serving that file (in the example above, we are only serving the HTML-file). To fix this we can define a directory of static files, where we can store assets like favicons, images, scripts and stylesheets.

Let's make a folder in our project root called public, and make a folder inside called style. In there we can put the stylesheet that we want to use on our HTML-page. so from the project root we have: /public/style/frontpage.css, which we now serve in app.js:

Now our stylesheet will be available at /style/frontpage.css, and we can use it in the head of our HTML-page like so: <link rel="stylesheet" href="/style/frontpage.css"/>
