Arrays in JavaScript

Contrary to languages like C++ and Java, arrays in JavaScript are dynamically sized and can contain values of multiple types in the same array:

Array methods

Arrays have a series of built-in methods to mutate the array, with names largely borrowed from the stack data-structure.

push()

arr.push(element) inserts one or more elements at the end of the array.

pop()

arr.pop() removes the last element of an array and returns it.

unshift()

arr.unshift(element) inserts one or more elements to the start of the array.

shift()

arr.shift() removes the first element in the array and returns it.

at()

arr.at(index) returns the element at the given index. Can also be used to find an element n indices from the end of the array:

Note that searching from the back of the array is not 0-indexed, and thus arr.at(-1) returns the very last element in the array.

indexOf()

arr.indexOf(element) returns the index of the first occurrence of an element, or -1 if no result was found

includes()

arr.includes(element) returns a boolean value representing whether or not the array contains the given element

splice()

arr.splice(start, deleteCount, ...elements) is used to insert, remove or replace a number of elements at specific indices in an array:

slice()

arr.slice(start, end) returns a subsection of an existing array starting at the index of the first parameter, and ending before the index of the second parameter. If no end index is given, the method returns the rest of the original array from the start index

Loop methods

While JavaScript does support all the standard loops like for, while and do-while, when you have to iterate over an array or map, these are often eschewed in favor of a handful of built-in iteration methods.

reduce()

arr.reduce(function) is used to reduce an array down to a single value. It takes a callback function as parameter, which is called with two arguments: the accumulator which holds every combined value so far, and the value of the current element.
