What is node.js

Node.js is a JavaScript runtime that runs outside of the web browser, enabling the development of server-side JavaScript applications.

While Node.js does come with a standard library of functionalities (which includes modules like fs for interacting with the file system, and path for working with file and directory paths), it is important to keep in mind that Node.js is just the tool that allows the developer to develop, build and run JavaScript applications outside of a browser environment, and not a coding language in itself.

The NPM package manager

Node.js comes with a package manager called the 'node package-manager' (or npm for short), which is used for managing and installing dependencies, as well as publishing your own packages. Dependencies declared with npm live in the package.json file at the root-directory of the project, and can be installed with the command npm install. Declaring and installing a new dependency with npm is done with the command npm install <package-name>. It is also possible to initialize a new Node.js project with the command npm init.
